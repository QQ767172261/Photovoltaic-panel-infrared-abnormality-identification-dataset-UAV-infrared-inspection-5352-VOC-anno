# 无人机光伏板红外异常识别数据集![在这里插入图片描述](https://i-blog.csdnimg.cn/direct/61edd8255cfa4b4e8ef09ab2607e6a16.png)


| 项目 | 详情 |
| --- | --- |
| 数据集名称 | 光伏板红外异常识别数据集 |
| 采集方式 | 行业级无人机仿地飞行采集，同步获取红外温度图像 |
| 任务类型 | 目标检测（细粒度光伏红外缺陷识别） |
| 图像总量 | 5352+张光伏红外图像 |
| 图像预处理 | 统一缩放至640×640，**未做数据增强处理** |
| 标注格式 | Pascal VOC（xml标注文件） |
| 缺陷标签 | 统一标签：Thermal Defects（红外热缺陷，不细分温度异常、电气故障、划痕、破损等子类别） |
| 数据集划分 | 训练集train：3748+张图像+对应xml标注   验证集valid：1071+张图像+对应xml标注   测试集test：533+张图像+对应xml标注   支持使用者重新自主划分数据集 |
| 数据目录结构 | Data Files（train、valid、test文件夹） + README.txt数据集说明文档 |
| 图像特点 | 单张图可无缺陷、含单个或多个红外异常目标 |

## 应用价值

1. **光伏无人机智能巡检模型训练**：面向红外热成像图训练AI检测模型，自动识别光伏组件热缺陷，替代人工目视判读红外影像。
2. **光伏电站运维降本增效**：快速定位光伏板热异常区域，及时消缺，减少发电量损失，延长组件寿命，降低电站运维人力成本。
3. **行业数字化转型**：助力光伏运维从传统人工巡检模式向无人机+AI智能化巡检模式升级。
4. **科研与项目验证**：适用于计算机视觉、红外图像目标检测相关课题研究，支撑光伏巡检AI项目算法验证。

## 适用人群

- 光伏电站运维企业、新能源电站巡检技术团队
- 无人机航测服务商，承接光伏红外巡检项目的技术人员
- 高校、科研院所，从事红外图像、能源装备缺陷检测方向课题组
- AI算法开发公司，开发光伏设备缺陷识别系统的研发人员

## 摘要


本数据集由行业无人机仿地飞行采集光伏电站红外热成像图像，总计5352+张，图像统一预处理至640×640，采用VOC(xml)标注格式，缺陷统一标注为Thermal Defects。数据集划分训练、验证、测试子集，单图可包含0个或多个红外缺陷目标。适用于光伏电站无人机红外智能巡检算法训练，实现光伏板热异常自动识别，支撑新能源光伏运维智能化升级。
